One pre-allocated pool of Float32 buffers ping-pongs through frameChannel: the worker free-runs the synth faster than the screen refreshes, so intermediate frames drop (latest-wins) and memory stays flat. The second tab transfers the canvas to the worker with transferControlToOffscreen() — the worker then draws its own frames and the main thread does nothing, so no channel is needed.
