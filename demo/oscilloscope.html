One pre-allocated pool of Float32 buffers ping-pongs through frameChannel: the worker free-runs the synth faster than the screen refreshes, so intermediate frames drop (latest-wins) and memory stays flat. The second tab uses adoptCanvas() — transferControlToOffscreen() plus resize + visibility forwarding — so the worker draws its own frames, auto-pauses when the tab is hidden, and the main thread does nothing. The channel readout shows which transport frameChannel negotiated: shared (SharedArrayBuffer + Atomics seqlock) when the page is cross-origin isolated, otherwise transfer — the fallback is silent and nothing else changes.
